# Changelog

All notable changes to the dungeon crawler, newest first. One section per version; a version is a git tag `vX.Y.Z` on `main`.
Convention: at each milestone add a section here (Added / Changed / Fixed, one line per commit worth naming), bump the minor version, tag it, push the tag.
