# THE DESCENT — a dungeon crawler game show (Voxelith)

Working title: **THE DESCENT™: Season 7, Floor 1 — "The Welcome Back Basement"**.
A vertical slice made with the Voxelith engine (docs/GUIDE.md). It is also the first outside test of the engine: see `ENGINE_FEEDBACK.md`.

> Status: **PLAN** (see "Build order" at the bottom for what is done; this file is updated with every step).

## The pitch
You are **Contestant #4,471,902**. You did not sign up. You are on *The Descent*, a game show broadcast to eleven galaxies in which contestants descend a bottomless
dungeon floor by floor. The show is hosted by **GLEE** (General Logistics & Entertainment Engine), a cheerful, sardonic AI that comments on everything you do — your
kills, your deaths, your inventory, your haircut — through the HUD and a synthesised "voice". Between floors there is a **Stairwell**: a safe room with a vending machine,
a save crystal and a very small amount of dignity. Your companion is **Admiral Honk**, a goose with a naval rank and a grudge.

Tone: cruel game show, corporate euphemism ("Your demise has been rescheduled"), dark humour, absurd achievements, loot boxes with tiers. All names and jokes are original.

## How it plays
* First person, WASD + mouse, **LMB attack**, **RMB / Q class ability**, **E interact**, **I inventory**, **C character sheet**, **1-8 hotbar** (use item), **0 camera** (first / third), **F5 screenshot**, **F11 save**.
* **Classes** (picked at the start): *Janitor* (mop sweeps, tanky, bucket splash), *Pyromaniac* (fire bolt, sets things alight), *Bard* (sonic shout, cheers heal), *Accountant* (audit: marks a target for crit damage, loot bonus).
* **Stats**: STR, DEX, INT, CON, CHARM. Level up from XP, +stat points to spend on the character sheet.
* **Loot boxes**: bronze / silver / gold / platinum "Crates of Consequence", opened with E; items have rarity and absurd names; **achievements** with absurd names pop up with GLEE's commentary.
* **Death** is a rescheduling: you wake at the last checkpoint, GLEE mocks you, you lose some gold. Checkpoints = the Stairwell and the Lobby crystal.
* **Floor 1** is a loop of differently built areas ending in the **Boss** (the Floor Manager) and the Stairwell with the way down.

## The floor (all inside the stone under a flat plain; the player never sees the surface)
Coordinates in the layout are metres from the lobby's south-west corner; the dungeon is carved into the stone around world (64 m, 7.5 m, 64 m).

| # | Area | What is in it | Systems used |

| A | **Intake Lobby** | the start: reception desk, queue ropes, class selection terminal, check-in crystal (save), tutorial crate, a sealed gate that opens after the intro | voxel text, prefabs, torches / emitters, lamps + doors (events), HUD class select, announcer |

| E | **The Gutter** | flooded sewer, raised walkways, slimes, a valve (lever) that drains the water; a chest that floods the room when taken | liquid sources, events, enemies |
| F | **Zero-G Ballroom** | weightless dance floor, floating loot, flip-gravity switch that turns the room upside down; a ceiling shortcut | gravity fields (null, uniform, retarget), events |
| G | **The Mushroom Grotto** | procedurally carved cave, glow caps, stalactites, pools, wildlife, the Goblin Foreman mini-boss | procedural carving, emitters (fireflies, spores), agents |

## How to run
```
./voxelith --manual --project projects/dungeon_crawler --time 0.75 --hud 0      # windowed (needs a display); --time 0.75 = midnight: the sky must not light the dungeon
./voxelith --mcp --project projects/dungeon_crawler --threads 3                  # the AI's way (.mcp.json), no HUD in screenshots
tools/hudshot.sh out.png [script]                                                # windowed in a private Xvfb + ffmpeg grab: the only way to SEE the Lua HUD without a display
./voxelith --check-project projects/dungeon_crawler
```
Delete `projects/dungeon_crawler/world.vxs*` (and `.state`, `.events`, `.prefabs`) to start a fresh run: the level builds its voxels only when `project.first_run()`.

## Testing without a keyboard
`on_hud` is not called in headless / MCP runs, so every game action is a global Lua function (`Game.attack()`, `Game.use_item(i)`, `Game.pick_class("janitor")` ...) that the HUD
triggers through `ui.run`; the tests call the same functions through the MCP `lua` tool (see "Test log" below).
